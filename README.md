# The largest box in a sparse random allocation

Companion material for the paper of the same title (Y. Shmalo, October 2026). [Read the paper](paper/main.pdf).

Throw m balls into n boxes so that an allocation (y_1, ..., y_n) has probability proportional to
w_{y_1} w_{y_2} ... w_{y_n}, for weights w_0 > 0 and w_1, w_2, ... ≥ 0. This is the balls-in-boxes model of
S. Janson, *Simply generated trees, conditioned Galton–Watson trees, random allocations and condensation*,
Probab. Surveys 9 (2012). Conjecture 19.4 of the survey states that if the generating function
Φ(t) = Σ w_k t^k has a positive radius of convergence and m/n → 0, then the largest box Y_(1) is o_p(log n).
The paper proves an explicit tail bound for Y_(1), valid for all n ≥ 4 and 1 ≤ m ≤ γn/4, and deduces that for
every δ > 0, with probability tending to one,

    Y_(1) ≤ C + (1 + δ) a log n / log(n/m),

where a is the smallest k ≥ 1 with w_k > 0 and C is the largest of the least elements of the residue classes
modulo a met by the monoid generated by {k ≥ 1 : w_k > 0} (C = 0 when w_1 > 0). This proves the conjecture.
For uniform weights the bound is attained when log(n/m) = o(log n), and neither the factor a nor the constant C
can be removed.

The proof compares Z(m − j, n − 1) with Z(m, n) directly. From an allocation of m − j balls into n − 1 boxes it
builds allocations of m balls into n boxes by adding an empty box and putting the j balls into p boxes that were
empty, and counting how often each allocation arises gives P(Y_1 = j) ≤ (w_j / w_0) (2m/(γn))^p. The arithmetic
of the set of box sizes allows p ≥ (j − C)/a.

## Contents

- `paper/` the LaTeX source and the compiled PDF.
- `code/checks.py` exact checks of the lemmas and of Theorem 1.1 for eight weight sequences, among them
  w_1 = 0 (a = 2, C = 3) and support {0, 3, 5} (a = 3, C = 10): the arithmetic of Lemma 2.1, the comparison of
  Lemma 3.2 against all allocations with n ≤ 7 and m ≤ 6, the bounds (1.2), (1.3) and (3.3) against the exact law
  of the largest box for every 4 ≤ n ≤ 64 and 1 ≤ m ≤ γn/4 and for n = 100, 200, 400 (39,151 inequalities), the
  formulas of Lemma 5.1 for uniform weights, and three negative controls, each of which must fail. It uses only
  the Python standard library and exact rational arithmetic. `code/checks.out` is its output.

The proofs are elementary and have not been formalized.

## Running the checks

    python code/checks.py

Python 3.8 or later. The script runs in about a minute and ends with `ALL CHECKS PASS`.
